# Changelog

All notable changes to OpenLearn AI will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- **Core AI Simplification Engine:** 4 comprehension tiers (Beginner, School, High School, University).
- **Multilingual Academic Translation:** Accurate domain terminology preservation with side-by-side verification.
- **Revision Study Notes:** Automatic extraction of definitions, formulas, and interactive checklists.
- **Flashcards & Quizzes:** 3D flip card interactions with keyboard navigation and 4-option quizzes.
- **Listen & Learn Suite:** Synchronized sentence karaoke reader using Web Speech API with speech rate controls.
- **Document Input:** Support for pasting text, uploading `.txt`, `.md`, and multimodal PDF / image extraction.
- **WCAG 2.2 AA Accessibility:** High contrast mode, text scaling up to 140%, and Lexend dyslexic font.
- **Offline Library:** Local `localStorage` persistence with JSON export and granular item management.
