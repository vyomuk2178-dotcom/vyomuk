# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
The OpenLearn AI team takes security and student privacy seriously.

If you believe you have found a security vulnerability:
1. Do not report security vulnerabilities through public GitHub issues.
2. Email maintainers or submit a private security advisory on GitHub.
3. Include detailed steps to reproduce the vulnerability.

We aim to acknowledge reports within 48 hours and release patches in a timely manner.
