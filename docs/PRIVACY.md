# Privacy & Data Governance Policy

OpenLearn AI operates under strict privacy-by-design standards:

1. **Local-First Retention:** Saved library entries, preferences, and recent documents exist only in your browser's `localStorage`.
2. **Ephemeral AI Processing:** Content submitted to `/api/simplify`, `/api/translate`, `/api/notes`, or `/api/activities` is passed in memory to the Gemini API solely to generate the requested response. Content is never stored in persistent databases.
3. **User Data Portability:** Users can export all stored data at any time via **Library > Export Library (JSON)**.
4. **Permanent Purging:** Users can irreversibly delete all local storage records using **Settings > Clear All Local App Data**.
5. **No Commercial Profiling:** We do not track user identities, serve ads, or sell data.
